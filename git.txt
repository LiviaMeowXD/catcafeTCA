Sempre que entrar em um pc novo:
	cd pasta-do-fabiano/trabalhos/TCA
	git config --local user.name "livia"
	git config --local user.email "email-da-conta-do-github"
Comandos
	git add <arquivo> -> Começa a rastrear um arquivo (ele vira parte do commit)
	git commit -m "mensagem" -> Escreve uma mensagem para o commit e fecha o ciclo.
	git push HEAD:main-> manda para o repositório do github o que foi feito nos ultimos commits.
